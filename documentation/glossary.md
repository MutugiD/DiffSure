# Glossary

- **Candidate:** One immutable patch lineage plus its observed evidence.
- **Clean-copy gate:** Independent final verification on a fresh snapshot.
- **Derived check:** An executable check created from the task before candidate
  source is visible.
- **Evidence:** An append-only observed result from a static or dynamic check.
- **Finalization reserve:** Deadline time unavailable to new model work and
  reserved for selection, clean verification, and response serialization.
- **Provider:** An adapter that produces normalized model turns and usage.
- **Record:** The ordered public sequence of assistant turns and tool results.
- **Snapshot:** The validated immutable repository received by `/solve`.
- **Viable candidate:** A candidate that has passed every mandatory gate seen so
  far.
