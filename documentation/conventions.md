# Documentation Conventions

- Use repository-relative Markdown links.
- Keep requirements testable and identify their evidence.
- Use Mermaid for version-controlled architecture diagrams.
- Record durable design choices as numbered architecture decision records.
- Treat accepted decisions as immutable; supersede them with a new record.
- Keep live benchmark claims tied to a dated report and provider configuration.
- Do not include secrets, private acceptance material, generated candidate
  source, or tool attribution in documentation.
